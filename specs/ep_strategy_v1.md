# EP 策略规格书：EP 单因子 v1

版本：v1.1
日期：2026-09-20
状态：已确认

## 一、意图

用 EP（利润市值比）因子选股，季度调仓，持有 Top N 等权。
EP 因子已在 records/ep/ep_v1.md 验证（ICIR 0.861，63 日窗口最优）。

## 二、九维度规格

| 维度 | 内容 | 用户确认 |
| ---- | ---- | ---- |
| 股票池 | 全 A 股（预测值表已过滤 ST）；策略端过滤停牌、涨跌停、上市不足 60 日的新股；不退市股 | ☑ |
| 因子定义 | EP = n_income / total_mv，rank 标准化到 [0,1] | ☑ |
| 调仓频率 | 固定季度调仓：每年 1/4/7/10 月第一个交易日 | ☑ |
| 持仓规则 | Top 50 等权（EP 的 Q5-Q1 月均 +2.229%、ICIR 0.861；Top 50 兼顾集中度与换手成本） | ☑ |
| 买卖约束 | 过滤停牌 + 涨跌停 + 日均成交额 < 5000 万 | ☑ |
| 交易成本 | 引用 specs/costs/standard.md（股票口径：印花税 0.0005 卖出、佣金 0.0000854、最低 5 元、滑点 0.0005） | ☑ |
| 基准 | 中证全指 000985.XSHG（股票池为全 A 股，故基准用中证全指） | ☑ |
| 评估区间 | 样本内 2016-02-01 至 2022-12-31；样本外 2023-01-01 至 2026-09-01 | ☑ |
| 风控 | 无止损，满仓；单股上限 5%（防止停牌权重漂移） | ☑ |

## 三、回测契约

- 主回测：2016-02-01 至 2026-09-01
- 样本内：2016-02-01 至 2022-12-31
- 样本外：2023-01-01 至 2026-09-01
- 三次回测串行提交（聚宽并行上限 2，第三次会被拒）
- 初始资金：100000
- 频率：day
- 基准：000985.XSHG
- 是否覆盖：否

## 四、数据契约

- 数据源：本地预测值表 predictions_ep_v1.csv（583,926 行 / 18.3 MB / 128 个调仓日 / 5,788 只股票）
- 预测值表路径（聚宽）：/predictions/ep/predictions_ep_v1.csv
- 复权方式：前复权
- PIT 约束：调仓日用表中最新的预测值（预测值表由 T-1 及更早数据生成）
- 上传形态：先单文件上传（18.3 MB），实测 read_file 性能后决定是否按年份切分

## 五、策略逻辑

1. 每季度第一个交易日（rebalance_date）
2. 从预测值表读取当日的所有 (symbol, value)
3. 过滤不可交易（涨跌停、停牌、流动性 < 5000 万）
4. 取 value 最高的 50 只
5. 等权买入，卖出不在 Top 50 的持仓
6. 季度内不做调仓

## 六、落地细节

### 6.1 初始资金与容量

- 初始资金：10 万
- Top 50 等权 = 单股 2000 元
- 如成交率 < 90%，减到 Top 30
  成交率定义：目标持仓成功建立的比例 = 实际买入股数 / 目标买入股数。
  阈值 90%：如某期成交率 < 90%，下一期持仓数从 Top 50 降到 Top 30。

### 6.2 调仓执行时点

- 每季度第一个交易日开盘执行
- 用调仓日当日的预测值表记录（表内该日的 value 由 T-1 及更早数据生成，PIT 安全）
- 单股上限 5% 的回归：如某股因停牌导致权重漂移超 5%，不主动减仓，
  下次季度调仓时按新目标权重自动回归。
- 基准 000985.XSHG 已在聚宽验证可用（指数代码，无需成分股数据）。

### 6.3 数据缺失降级

- 单股无 value：跳过该股
- 当日预测值表整体缺失：本期不调仓，保持上期持仓

### 6.4 上传形态

- 先单文件上传（18.3 MB）
- 实测读取性能后再决定是否切分

## 七、已知局限

- 样本外 IC 0.0205、t 0.85 不显著（44 个月）
- 未做 Alpha/Beta 分解
